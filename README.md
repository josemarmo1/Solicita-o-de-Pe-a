Central de Pedidos — Amado Maker

Sistema web para gerenciamento e envio de solicitações técnicas e pedidos de peças.

Projeto desenvolvido para otimizar o fluxo de solicitações entre equipes, centralizando informações de solicitantes, equipamentos, itens, endereços de entrega e anexos em uma única interface.

Tecnologias
HTML5
CSS3
JavaScript
Supabase
PostgreSQL
GitHub Pages
jsPDF
API / Edge Functions
Principais funcionalidades
Cadastro de solicitante
Cadastro dinâmico de itens
Identificação do equipamento
Cadastro de endereço de entrega
Endereços salvos
Upload de anexos
Integração com Supabase
Envio automático de pedidos
Geração de comprovante em PDF
Integração com WhatsApp
Interface responsiva para computador e celular
Objetivo

O sistema foi desenvolvido para transformar um processo manual de solicitação em um fluxo digital, organizado e padronizado.
